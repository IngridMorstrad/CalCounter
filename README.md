# CalCounter

A simple Android calorie counter app built with Java and Room database.

## Features

- Track daily calorie intake
- Add and manage food entries
- View calorie history with charts
- Configurable daily calorie goal via settings

## Tech Stack

- Java
- Android Room (SQLite)
- MPAndroidChart for charting
- RecyclerView for list displays

## Getting Started

1. Clone the repository
2. Open the project in Android Studio
3. Build and run on an emulator or device

## Project Structure

- `app/src/main/java/` — Main application source code
- `app/src/main/res/` — Layouts, menus, and resources
- `app/src/main/res/xml/` — Preferences configuration
