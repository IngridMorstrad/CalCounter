# CalCounter

A simple Android calorie counter app built with Java and Room database.

## Features

- Track daily calorie intake
- Add and manage food entries
- View calorie history with charts
- Configurable settings

## Getting Started

1. Clone the repository: `git clone https://github.com/IngridMorstrad/CalCounter.git`
2. Open the project in Android Studio.
3. Sync Gradle dependencies and build the project.
4. Run the app on an emulator or connected device.
5. Start logging your daily calorie intake!

## Tech Stack

- Java
- Android Room (SQLite)
- MPAndroidChart
